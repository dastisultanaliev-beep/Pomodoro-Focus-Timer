# Pomodoro Focus Timer 🍅

A desktop productivity application built with Python and CustomTkinter using the Pomodoro Technique.

## Features

- 25-minute work sessions.
- 5-minute short breaks.
- 15-minute long breaks.
- Automatic switching between work and break sessions.
- Circular progress indicator.
- Start, pause, reset, and skip controls.
- Daily Pomodoro statistics.
- Weekly productivity chart.
- Data saved in JSON format.
- Desktop notifications and sound alerts.
- Dark theme.

## Technologies

- Python
- CustomTkinter
- Tkinter
- JSON
- Datetime
- Pathlib
- Plyer (optional, for notifications)

## Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Install the required packages:

   ```bash
   pip install customtkinter plyer
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## Data Storage

The application automatically creates `pomodoro_data.json` to store daily productivity statistics.
